## This port

- **Licence:** GNU LGPL v2.1, the same terms as the original's code. The full text is in
  [`LICENSE`](LICENSE) (the canonical text from gnu.org). No further restriction is added.
- **Corresponding source:** published with the port — the Rust sources under `src/`, the
  generators under `tools/`, and the generated content under `assets/` and `data/`. The `.hmod`
  carries this notice and the licence text, so the notice travels with the artifact; the source
  that built it is this repository.
- **What it is:** a clean-room Rust rewrite of a slice of The Twilight Forest's behaviour (the
  portal's activation rule, and the dimension's registration and biome grid), written from the
  mod's public source and its own data files. It is not a translation of the Java code and
  contains none of it. `src/runtime.rs` is the campaign's pure rule with its own tests.

## The assets: the upstream art is CC-BY-NC-SA-4.0, so it is not carried

The code grant does not reach the art. Because a content port carries assets, the campaign first
recorded this port as **rank 4 — local-only** (ARCHITECTURE.md §8, ruling 2026-11-18). It is
publishable now for the same reason MineColonies is: **the code may be ported, and the art is
regenerated by the port.**

- **Every packaged asset is this port's own work.** The three `deadrock` textures are drawn by
  [`tools/assemble_surface_blocks.py`](tools/assemble_surface_blocks.py); the portal barrier's
  swirl and its animation are drawn, frame by frame, by
  [`tools/gen_portal_texture.py`](tools/gen_portal_texture.py); the models, blockstates, item
  files, loot tables, tags, lang file and block declarations are written by
  [`tools/assemble_content.py`](tools/assemble_content.py) and
  [`tools/assemble_worldgen.py`](tools/assemble_worldgen.py).
- **No upstream byte travels.** [`tools/check_provenance.py`](tools/check_provenance.py) compares
  the sha256 of every packaged file with every entry of the jar and fails the build on a match;
  [`PROVENANCE.md`](PROVENANCE.md) is its report, one line per packaged file naming the generator
  or the rewrite that produced it. The measured result is **0 identical files**.
- **The 0.1.0 portal art is gone.** Its blockstate, barrier model, texture, animation and three
  tags were carried verbatim from the jar; all seven were re-authored in this pass (same states,
  same geometry, same membership — the port's own bytes, ordering and formatting).
- **Worldgen data is converted, not copied.** `tools/assemble_worldgen.py` reads the jar's own
  biome, surface-rule and noise-settings definitions and writes 26.3's shape from them: the
  mod's *design* (colours, climate, block ids), which is code-side data, never a texture, model or
  lang file. Each of those files is rewritten from semantics, and none is byte-identical to the
  jar's.
